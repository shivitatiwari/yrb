# Yrb v1.7.0

This release replaces the layered normal-path YouTube extraction logic with a single authenticated yt-dlp path inspired by the architectural patterns used by Seal, while keeping Yrb's implementation independent.

Key changes:

- full Android WebView cookie-database export for YouTube/Google session data
- matching browser User-Agent on yt-dlp metadata and download requests
- authenticated `default,web_embedded` YouTube client selection
- one fast metadata request before any recovery path
- 5 second socket timeout / one retry
- background yt-dlp refresh
- automatic migration of existing WebView sessions
- yt-dlp-managed temp/final paths
- recoverable page-reload and empty-file failures
- existing quality, file-size, language, progress, History and notification UX retained

A hard two-second metadata guarantee is not possible because YouTube/network latency is external, but Yrb no longer performs sequential client probing on the successful path.
