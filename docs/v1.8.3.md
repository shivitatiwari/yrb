# Yrb v1.8.3

## Purpose

Fix the optimized-build regression where the embedded downloader could reach the UI without a successfully initialized yt-dlp runtime.

## Fixes

- Explicitly sets `android:extractNativeLibs="true"` for the embedded native Python/yt-dlp runtime.
- Adds idempotent yt-dlp + FFmpeg initialization and retries it before inspection and background download work.
- Retains ABI-specific APKs and local vector icons.
- Disables R8/resource shrinking for direct-install APKs because runtime correctness is more important than the relatively small extra savings from shrinking.
- Preserves all existing download, audio, language, progress, history and 4.7-second loading-state behavior.

## Distribution

The arm64-v8a APK remains the primary build for modern Android phones.
