# Yrb v1.9.0

## Goal

Remove avoidable latency from video inspection and download startup without moving extraction or media processing off-device.

## Inspection fast path

- Initialize the embedded runtime immediately without waiting behind the daily updater lock.
- Delay the once-daily yt-dlp background updater by 60 seconds after app startup.
- Perform one normal extractor pass with:
  - `--dump-single-json`
  - `--skip-download`
  - `--no-check-formats`
  - 4 second socket timeout
  - zero generic retries
  - zero extractor retries
- Do not force an yt-dlp update and repeat extraction inside the user-facing Inspect request.

## Download fast path

- Persist the successful raw yt-dlp inspection JSON for 10 minutes under app-private no-backup storage.
- Carry that cached info path with every video quality and audio-only option.
- Start the selected download with yt-dlp `--load-info-json` instead of extracting the YouTube page again.
- Keep the existing recovery extraction path for expired/rejected cached media routes.

## Preserved behavior

- yt-dlp + bundled Python + FFmpeg remain fully on-device.
- 360p through 4K quality selection remains.
- Audio-only and language selection remain.
- Live progress, speed, ETA, cancellation, History and notifications remain.
- ABI-specific APK packaging and native-library extraction remain.
- Loading-state text still rotates every 4.7 seconds.

## Validation

GitHub Actions runs unit tests, lint, ABI APK builds and release AAB generation before publishing the release.
