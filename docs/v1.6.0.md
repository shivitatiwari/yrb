# Yrb v1.6.0

- Validate completed media inside each download attempt before leaving the recovery loop.
- Treat zero-byte output as a failed playback route instead of finalizing a broken file.
- Reuse the existing alternate-route recovery for empty results.
- Put YouTube connection state ahead of the download field when connection is needed.
- Collapse connected state into a compact status row so the download controls stay primary.
- Send session-related errors directly to the in-app sign-in flow.
- Preserve live progress, speed, ETA, file-size estimates, audio-language selection, History, notifications and on-device yt-dlp/FFmpeg.

Known limitation:
- The embedded login activity itself is unchanged in this build; the requested page-loading bar was not modified.
