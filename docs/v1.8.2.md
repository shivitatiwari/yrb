# Yrb v1.8.2

## Goal

Reduce APK size without changing the local downloader architecture or removing download features.

## Changes

- Four ABI-specific direct-install APKs: arm64-v8a, armeabi-v7a, x86, x86_64.
- R8 and resource shrinking enabled for optimized builds.
- material-icons-extended removed; eight used icons are local vector drawables.
- yt-dlp 0.18.1, bundled Python and FFmpeg remain intact.
- Loading/preparation state rotation remains 4.7 seconds.

## Signing

Direct-install APKs use the CI debug signing key. The release AAB remains unsigned until production signing credentials are configured securely.

## Release pipeline

CI verifies unit tests and lint, builds the optimized ABI APKs and release AAB, uploads the artifacts, and publishes the GitHub Release.

## CI validation note

The local-vector migration covers both the main downloader UI and the YouTube session screen.
