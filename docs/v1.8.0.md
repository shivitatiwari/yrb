# YRB 1.8.0

## Scope

This release focuses on perceived responsiveness, audio-only downloads and creator branding.

## User experience

Inspection no longer presents one static spinner. While metadata work is running, the screen rotates through these status messages every 2.7 seconds:

1. Reading video details
2. Finding video streams
3. Finding audio tracks
4. Finding languages
5. Checking quality options
6. Preparing choices

After a user chooses video quality or audio-only, the Download screen displays a separate preparation sequence until the downloader reports real written bytes/progress. It then returns to real progress, speed, ETA and written-byte telemetry.

## Audio-only pipeline

YRB now exposes the best detected audio-only stream for the selected language. The stream is downloaded locally through the existing yt-dlp foreground service and finalized as M4A using the bundled FFmpeg integration. The same History, notifications, cancellation, recovery routing and size estimation paths are reused.

Audio-only history records use quality value 0 internally and render as **Audio only** in the UI and completion notification.
